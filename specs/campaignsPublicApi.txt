## Schemas

### StandardError
  - category (string): A string that categorizes the type of error.
  - context (object): An object containing additional context about the error, with keys as context names and values as arrays of strings.
  - errors (array): An array of ErrorDetail objects providing further information about each error encountered.
  - id (string): A string representing a unique identifier for the error.
  - links (object): An object mapping link names to associated URIs that contain documentation or remediation steps for the error.
  - message (string): A string containing a human-readable message describing the error.
  - status (string): A string indicating the status of the error.
  - subCategory (object): An object that provides more specific details about the error category.

### PublicCampaignBatchUpdateItem
  - id (string): The unique identifier for the campaign to be updated.
  - properties (object): A set of key-value pairs representing the properties to be updated for the campaign.

### CollectionResponsePublicCampaignAssetForwardPaging
  - paging (): 
  - results (array): An array of public campaign assets. Each item in the array is a reference to a PublicCampaignAsset object.

### PublicCampaignReadInput
  - id (string): The unique identifier for a campaign.

### BatchResponsePublicCampaignWithAssetsWithErrors
  - completedAt (string): The date and time when the batch operation was completed.
  - errors (array): 
  - links (object): A collection of links related to the batch operation.
  - numErrors (integer): The number of errors that occurred during the batch operation.
  - requestedAt (string): The date and time when the batch operation was requested.
  - results (array): 
  - startedAt (string): The date and time when the batch operation started.
  - status (string): The current status of the batch operation, which can be CANCELED, COMPLETE, PENDING, or PROCESSING.

### BatchInputPublicCampaignReadInput
  - inputs (array): An array of PublicCampaignReadInput objects, each containing the ID of a campaign to be read. This property is required.

### BatchResponsePublicCampaignWithAssets
  - completedAt (string): The timestamp when the batch request processing was completed.
  - links (object): A collection of URLs linking to related resources or documentation.
  - requestedAt (string): The timestamp when the batch request was initially made.
  - results (array): An array of results from the batch operation, each representing a public campaign with assets.
  - startedAt (string): The timestamp when the processing of the batch request began.
  - status (string): The current processing status of the batch operation, with possible values: CANCELED, COMPLETE, PENDING, PROCESSING.

### CollectionResponseWithTotalPublicCampaign
  - paging (): 
  - results (array): An array of PublicCampaign objects, each representing a campaign with its associated properties.
  - total (integer): An integer representing the total number of public campaigns available.

### BatchResponsePublicCampaignWithErrors
  - completedAt (string): The date and time when the batch operation was completed.
  - errors (array): 
  - links (object): URLs linking to resources or documentation related to the batch operation.
  - numErrors (integer): The total number of errors encountered during the batch operation.
  - requestedAt (string): The date and time when the batch request was made.
  - results (array): 
  - startedAt (string): The date and time when the batch operation began.
  - status (string): The current status of the batch operation. Accepted values are: CANCELED, COMPLETE, PENDING, PROCESSING.

### ErrorDetail
  - code (string): The status code associated with the error detail
  - context (object): Context about the error condition
  - in (string): The name of the field or parameter in which the error was found.
  - message (string): A human readable message describing the error along with remediation steps where appropriate
  - subCategory (string): A specific category that contains more specific detail about the error

### PublicSpendItem
  - amount (number): The monetary value associated with the spend item.
  - createdAt (integer): The timestamp indicating when the spend item was created.
  - description (string): A detailed explanation or notes about the spend item.
  - id (string): Unique identifier for the spend item.
  - name (string): The name assigned to the spend item.
  - order (integer): The sequence order of the spend item, where 0 is the oldest.
  - updatedAt (integer): The timestamp indicating when the spend item was last updated.

### BatchResponsePublicCampaign
  - completedAt (string): The date and time when the batch operation was completed, formatted as a date-time string.
  - links (object): A map of related links associated with the batch operation.
  - requestedAt (string): The date and time when the batch operation was requested, formatted as a date-time string.
  - results (array): An array of results from the batch operation, each item representing a public campaign.
  - startedAt (string): The date and time when the batch operation started, formatted as a date-time string.
  - status (string): The current status of the batch operation, with possible values: CANCELED, COMPLETE, PENDING, PROCESSING.

### PublicCampaignWithAssets
  - assets (object): Contains the assets associated with the campaign, each represented as a collection of campaign assets.
  - businessUnits (array): An array of business units associated with the campaign, each represented by a PublicBusinessUnit object.
  - createdAt (string): The date and time when the campaign was created, formatted as a date-time string.
  - id (string): The unique identifier for the campaign.
  - properties (object): A map of key-value pairs representing the properties of the campaign.
  - updatedAt (string): The date and time when the campaign was last updated, formatted as a date-time string.

### PublicBudgetTotals
  - budgetItems (array): An array of budget items associated with the campaign. Each item is represented by a PublicBudgetItem object.
  - budgetTotal (number): The total budget allocated for the campaign.
  - currencyCode (string): The currency code used for the budget and spend amounts, following ISO 4217 standards.
  - remainingBudget (number): The remaining budget available for the campaign after accounting for all spend items.
  - spendItems (array): An array of spend items associated with the campaign. Each item is represented by a PublicSpendItem object.
  - spendTotal (number): The total amount spent across all spend items in the campaign.

### BatchInputPublicCampaignDeleteInput
  - inputs (array): An array of PublicCampaignDeleteInput objects, each specifying a campaign to be deleted. Each object must include the campaign's unique identifier.

### CollectionResponsePublicCampaignAsset
  - paging (): 
  - results (array): An array of public campaign assets. Each item in the array is an object representing a campaign asset.

### PublicCampaignDeleteInput
  - id (string): The unique identifier for the campaign to be deleted.

### PublicSpendItemInput
  - amount (number): The monetary value of the spend item.
  - description (string): A brief description of the spend item.
  - name (string): The name of the spend item.
  - order (integer): The sequence number indicating the order of the spend item.

### PublicCampaignInput
  - properties (object): A collection of key-value pairs representing the properties of the campaign. Each key is a property name, and the corresponding value is the property's value.

### MetricsCounters
  - influencedContacts (integer): The number of contacts influenced by the campaign.
  - newContactsFirstTouch (integer): The number of new contacts attributed to the campaign as the first touchpoint.
  - newContactsLastTouch (integer): The number of new contacts attributed to the campaign as the last touchpoint.
  - sessions (integer): The total number of sessions generated by the campaign.

### PublicBudgetItem
  - amount (number): The monetary amount allocated for the budget item.
  - createdAt (integer): The timestamp when the budget item was created.
  - description (string): A description of the budget item.
  - id (string): The unique identifier for the budget item.
  - name (string): The name of the budget item.
  - order (integer): The order of the budget item, indicating its sequence based on creation date.
  - updatedAt (integer): The timestamp when the budget item was last updated.

### BatchInputPublicCampaignInput
  - inputs (array): An array of PublicCampaignInput objects, each representing the properties of a campaign to be created in the batch. This property is required.

### PublicBudgetItemInput
  - amount (number): The monetary value assigned to the budget item.
  - description (string): A detailed explanation or notes about the budget item.
  - name (string): The name of the budget item.
  - order (integer): The sequence number indicating the order of the budget item.

### Error
  - category (string): The error category
  - context (object): Context about the error condition
  - correlationId (string): A unique identifier for the request. Include this value with any error reports or support tickets
  - errors (array): further information about the error
  - links (object): A map of link names to associated URIs containing documentation about the error or recommended remediation steps
  - message (string): A human readable message describing the error along with remediation steps where appropriate
  - subCategory (string): A specific category that contains more specific detail about the error

### CollectionResponseContactReferenceForwardPaging
  - paging (): 
  - results (array): An array of contact references, each containing an identifier for a contact.

### PublicCampaignAsset
  - id (string): The unique identifier for the campaign asset.
  - metrics (object): A collection of metrics associated with the campaign asset, represented as key-value pairs.
  - name (string): The name of the campaign asset.

### RevenueAttributionAggregate
  - contactsNumber (integer): The number of contacts attributed to the campaign.
  - currencyCode (string): The currency code used for the revenue attribution, with accepted values including AED, AFN, ALL, and others.
  - dealAmount (number): The total amount of deals attributed to the campaign.
  - dealsNumber (integer): The number of deals attributed to the campaign.
  - revenueAmount (number): The total revenue amount attributed to the campaign.

### BatchInputPublicCampaignBatchUpdateItem
  - inputs (array): An array of PublicCampaignBatchUpdateItem objects, each containing the ID and properties to update for a specific campaign.

### PreviousPage
  - before (string): A string token that indicates the position in the list before the current page of results.
  - link (string): A string containing the URL link to the previous page of results.

### ContactReference
  - id (string): Unique identifier for the contact.

### PublicBusinessUnit
  - id (integer): The unique identifier for the business unit, represented as an integer.

### NextPage
  - after (string): A string token used as a cursor to retrieve the next page of results.
  - link (string): A string URL that provides the link to the next page of results.

### PublicCampaign
  - businessUnits (array): An array of business units associated with the campaign, each represented by a PublicBusinessUnit object.
  - createdAt (string): The date and time when the campaign was created, formatted as a date-time string.
  - id (string): The unique identifier for the campaign.
  - properties (object): A collection of key-value pairs representing additional properties of the campaign.
  - updatedAt (string): The date and time when the campaign was last updated, formatted as a date-time string.
