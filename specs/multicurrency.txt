## Schemas

### CompanyCurrency
  - createdAt (string, required): The date the company currency was created.
  - id (string, required): The currency code for the company currency

### PublicObjectId
  - id (string, required): A unique identifier for the exchange rate

### CollectionResponseExchangeRateNoPaging
  - results (array, required): 

### StandardError
  - category (string, required): The main category of the error.
  - context (object, required): Additional context-specific information related to the error.
  - errors (array, required): The detailed error objects.
  - id (string, optional): A unique ID for the error instance.
  - links (object, required): URLs linking to documentation or resources associated with the error.
  - message (string, required): A human-readable string describing the error and possible remediation steps.
  - status (string, required): The HTTP status code associated with the error.
  - subCategory (object, optional): A more specific error category within each main category.

### CompanyCurrencyUpdateRequest
  - currencyCode (string, required): The three-letter code representing a specific currency (ex. USD).

### ExchangeRate
  - conversionRate (number, required): The conversion rate between the to and from currency code of this exchange rate.
  - createdAt (string, required): The date the exchange rate was created.
  - effectiveAt (string, required): The date the exchange rate is in effect.
  - fromCurrencyCode (string, required): This represents the three-letter currency code (such as USD for US Dollar) of the currency you are converting from.
  - id (string, required): A unique identifier for the exchange rate
  - toCurrencyCode (string, required): This represents the three-letter currency code (such as USD for US Dollar) of the currency you are converting to.
  - updatedAt (string, required): The date the exchange rate was last updated.
  - visibleInUI (boolean, required): This indicates if the exchange rate is shown in the MultiCurrency settings page.

### CollectionResponseCurrencyCodeInfoNoPaging
  - results (array, required): 

### CurrencyCodeInfo
  - currencyCode (string, required): The three-letter code representing a specific currency (ex. USD).
  - currencyName (string, required): The full name of the currency (ex. US Dollar).

### CurrencyCreateRequest
  - currencyCode (string, required): The currency code being added to the HubSpot portal for use with central exchange rates.

### Error
  - category (string, required): The error category
  - context (object, optional): Context about the error condition
  - correlationId (string, required): A unique identifier for the request. Include this value with any error reports or support tickets
  - errors (array, optional): further information about the error
  - links (object, optional): A map of link names to associated URIs containing documentation about the error or recommended remediation steps
  - message (string, required): A human readable message describing the error along with remediation steps where appropriate
  - subCategory (string, optional): A specific category that contains more specific detail about the error

### BatchResponseExchangeRateWithErrors
  - completedAt (string, required): The datetime the response was completed
  - errors (array, optional): 
  - links (object, optional): The link to the next page with exchange rates.
  - numErrors (integer, optional): The number of errors associated to the request.
  - requestedAt (string, optional): The datetime the of the request.
  - results (array, required): 
  - startedAt (string, required): The datetime the of the request.
  - status (string, required): The current status of the response (e.g. COMPLETED)

### CurrencyPairUpdate
  - fromCurrencyCode (string, required): This represents the three-letter currency code (such as USD for US Dollar) of the currency you want to convert from.
  - toCurrencyCode (string, required): This represents the three-letter currency code (such as USD for US Dollar) of the currency you want to convert to.
  - visibleInUI (boolean, required): This indicates if the currency pair is shown in the MultiCurrency settings page. Setting this to false will remove the currency pair from the settings page.

### ErrorDetail
  - code (string, optional): The status code associated with the error detail
  - context (object, optional): Context about the error condition
  - in (string, optional): The name of the field or parameter in which the error was found.
  - message (string, required): A human readable message describing the error along with remediation steps where appropriate
  - subCategory (string, optional): A specific category that contains more specific detail about the error
