  - channelId (query, opt): Limits results to channel accounts within a particular channel.
  - defaultPageLength (query, opt): The default number of results to display per page.
  - inboxId (query, opt): Limits results to channel accounts within a particular inbox.
  - limit (query, opt): The maximum number of results to display per page.
  - sort (query, opt): The sort order for the channel accounts.

### GET /conversations/v3/conversations/threads
Get threads
  - after (query, opt): The paging cursor token of the last successfully read resource will be returned as the `paging.next.after` JSON property of a paged response containing more results.
  - archived (query, opt): Whether to return only results that have been archived.
  - associatedContactId (query, opt): Retrieve a filtered list of conversations for a specific contact by its ID. This parameter cannot be used in conjunction with the `inboxId` property.
  - association (query, opt): You can specify an association type here of `TICKET`. If this is set the response will included a thread associations object and associated ticket id if present. If there are no associations to a ticket with this conversation, then the thread associations object will not be present on the response. 
  - inboxId (query, opt): The ID of the conversations inbox you can optionally include to retrieve the associated messages for. This parameter cannot be used in conjunction with the `associatedContactId` property.
  - latestMessageTimestampAfter (query, opt): The minimum(earliest) `latestMessageTimestamp`. This is required only when sorting by `latestMessageTimestamp`.
  - limit (query, opt): The maximum number of results to display per page.
  - property (query, opt): A specific property to include in the thread response.
  - sort (query, opt): Set the sort order of the response. Valid options are `id` (default) and `latestMessageTimestamp` (which requires the `latestMessageTimestampAfter` field to also be set). If youâ€™re filtering threads by `associatedContactId` , you can sort in descending order by prepending - to the sort option (e.g., `-id` or `-latestMessageTimestampAfter` ). Otherwise, results are always returned in ascending order.
  - threadStatus (query, opt): The status of the associated conversations to filter by (either `OPEN` or `CLOSED`). This property must be provided if youâ€™re including the `associatedContactId` query parameter.
  Response 200: successful operation
  Response default: 

### GET /conversations/v3/conversations/threads/{threadId}
Get a single thread
  - archived (query, opt): Whether to return only results that have been archived. Default is false.
  - association (query, opt): You can specify an association type here of `TICKET`. If this is set the response will included a thread associations object and associated ticket id if present. If there are no associations to a ticket with this conversation, then the thread associations object will not be present on the response. 
  - property (query, opt): A specific property to include in the thread response.
  - threadId (path, req): The unique ID of the thread.
  Response 200: successful operation
  Response default: 

### DELETE /conversations/v3/conversations/threads/{threadId}
Archives a thread
  - threadId (path, req): The unique ID of the thread.
  Response 204: No content
  Response default: 

### PATCH /conversations/v3/conversations/threads/{threadId}
Update a thread
  - archived (query, opt): Whether the thread to update is archived. Default is false. A thread's status property can not be updated if the thread is archived.
  - threadId (path, req): The unique ID of the thread.
  Response 200: successful operation
  Response default: 

### GET /conversations/v3/conversations/threads/{threadId}/messages
Get message history for a thread
  - after (query, opt): The paging cursor token of the last successfully read resource will be returned as the `paging.next.after` JSON property of a paged response containing more results.
  - archived (query, opt): Whether to return only results that have been archived.
  - limit (query, opt): The maximum number of results to display per page.
  - property (query, opt): A specific property to include in the message response.
  - sort (query, opt): Sort direction. Valid options are `createdAt` (ascending), and `-createdAt` (descending, default)
  - threadId (path, req): The unique ID of the thread.
  Response 200: successful operation
  Response default:
