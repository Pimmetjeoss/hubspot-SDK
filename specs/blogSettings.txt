### Blog
  - absoluteUrl (string): Blog's root URL
  - allowComments (boolean): Boolean determining whether or not this blog allows public comments.
  - created (string): The timestamp (ISO8601 format) when this blog was created.
  - deletedAt (string): The timestamp (ISO8601 format) when this Blog was deleted.
  - description (string): The Description of this Blog.
  - htmlTitle (string): The html title of this Blog.
  - id (string): The unique ID of the Blog.
  - language (string): The explicitly defined language of the Blog. If null, the Blog will default to the language of the Domain.
  - listingPageId (string): 
  - name (string): The internal name of the blog.
  - publicAccessRules (array): Rules for require member registration to access private content.
  - publicAccessRulesEnabled (boolean): Boolean to determine whether or not to respect publicAccessRules.
  - publicTitle (string): The public title of this Blog.
  - slug (string): The path of the this blog. This field is appended to the domain to construct the url of this blog.
  - translatedFromId (string): ID of the primary Blog this object was translated from.
  - updated (string): The timestamp (ISO8601 format) when this blog was updated.

### NextPage
  - after (string): A paging cursor token for retrieving subsequent pages.
  - link (string): A URL that can be used to retrieve the next page results.

### VersionUser
  - email (string): The email address of the user.
  - fullName (string): The first and last name of the User.
  - id (string): The unique ID of the User.
