# Account Test Child Api
Get information about a HubSpot account and its API usage.

## Endpoints

### GET /account-info/v3/activity/login
Get login activity for a HubSpot account.
  - after (query, opt): The cursor token value to get the next set of results. You can get this from the `paging.next.after` JSON property of a paged response containing more results.
  - limit (query, opt): The maximum number of results to display per page. Max value of limit is 200.
  - userId (query, opt): Identifier of user to retrieve activities for
  Response 200: successful operation
  Response default:

### GET /account-info/v3/activity/security
Get security activity for a HubSpot account
  - after (query, opt): The cursor token value to get the next set of results. You can get this from the `paging.next.after` JSON property of a paged response containing more results.
  - limit (query, opt): The maximum number of results to display per page. Max value of limit is 200.
  - userId (query, opt): Identifier of user to retrieve activities for
  - fromTimestamp (query, opt): Limit to activities created after this epoch timestamp.
  Response 200: successful operation
