## Schemas

### PropertyName
  - name (string, required): The name of the property to read or modify.

### StandardError
  - category (string, required): The main category of the error.
  - context (object, required): Additional context-specific information related to the error.
  - errors (array, required): The detailed error objects.
  - id (string, optional): A unique ID for the error instance.
  - links (object, required): URLs linking to documentation or resources associated with the error.
  - message (string, required): A human-readable string describing the error and possible remediation steps.
  - status (string, required): The HTTP status code associated with the error.
  - subCategory (object, optional): A more specific error category within each main category.

### BatchResponseProperty
  - completedAt (string, required): The timestamp indicating when the batch operation was completed.
  - errors (array, optional): 
  - links (object, optional): A collection of URLs linking to documentation or resources related to the batch operation.
  - numErrors (integer, optional): The total number of errors encountered during the batch operation.
  - requestedAt (string, optional): The timestamp indicating when the batch operation was requested.
  - results (array, required): 
  - startedAt (string, required): The timestamp indicating when the batch operation began processing.
  - status (string, required): The current status of the batch operation, with possible values being CANCELED, COMPLETE, PENDING, or PROCESSING.

### PropertyGroup
  - archived (boolean, required): Indicates whether the property group is archived.
  - displayOrder (integer, optional): Property groups are displayed in order starting with the lowest positive integer value. Values of -1 will cause the property group to be displayed after any positive values.
  - label (string, required): A human-readable label that will be shown in HubSpot.
  - name (string, required): The internal property group name, which must be used when referencing the property group via the API.

### CollectionResponsePropertyGroupNoPaging
  - results (array, required): 

### PropertyCreate
  - calculationFormula (string, optional): Represents a formula that is used to compute a calculated property.
  - dataSensitivity (string, optional): Indicates the sensitivity level of the property, with options: highly_sensitive, non_sensitive, or sensitive.
  - description (string, optional): A description of the property that will be shown as help text in HubSpot.
  - displayOrder (integer, optional): Properties are displayed in order starting with the lowest positive integer value. Values of -1 will cause the property to be displayed after any positive values.
  - externalOptions (boolean, optional): Applicable only for 'enumeration' type properties.  Should be set to true in conjunction with a 'referencedObjectType' of 'OWNER'.  Otherwise false.
  - fieldType (string, required): Controls how the property appears in HubSpot.
  - formField (boolean, optional): Whether or not the property can be used in a HubSpot form.
  - groupName (string, required): The name of the property group the property belongs to.
  - hasUniqueValue (boolean, optional): Whether or not the property's value must be unique. Once set, this can't be changed.
  - hidden (boolean, optional): If true, the property won't be visible and can't be used in HubSpot.
  - label (string, required): A human-readable property label that will be shown in HubSpot.
  - name (string, required): The internal property name, which must be used when referencing the property via the API.
  - options (array, optional): A list of valid options for the property. This field is required for enumerated properties.
  - referencedObjectType (string, optional): Should be set to 'OWNER' when 'externalOptions' is true, which causes the property to dynamically pull option values from the current HubSpot users.
  - type (string, required): The data type of the property.

### OptionInput
  - description (string, optional): A description of the option.
  - displayOrder (integer, required): Options are shown in order starting with the lowest positive integer value. Values of -1 will cause the option to be displayed after any positive values.
  - hidden (boolean, required): Hidden options won't be shown in HubSpot.
  - label (string, required): A human-readable option label that will be shown in HubSpot.
  - value (string, required): The internal value of the option, which must be used when setting the property value through the API.

### Error
  - category (string, required): The error category
  - context (object, optional): Context about the error condition
  - correlationId (string, required): A unique identifier for the request. Include this value with any error reports or support tickets
  - errors (array, optional): further information about the error
  - links (object, optional): A map of link names to associated URIs containing documentation about the error or recommended remediation steps
  - message (string, required): A human readable message describing the error along with remediation steps where appropriate
  - subCategory (string, optional): A specific category that contains more specific detail about the error

### Property
  - archived (boolean, optional): Whether or not the property is archived.
  - archivedAt (string, optional): When the property was archived.
  - calculated (boolean, optional): For default properties, true indicates that the property is calculated by a HubSpot process. It has no effect for custom properties.
  - calculationFormula (string, optional): Represents a formula that is used to compute a calculated property.
  - createdAt (string, optional): The timestamp when the property was created, in ISO 8601 format.
  - createdUserId (string, optional): The internal user ID of the user who created the property in HubSpot. This field may not exist if the property was created outside of HubSpot.
  - dataSensitivity (string, optional): Indicates the sensitivity level of the property, such as "non_sensitive", "sensitive", or "highly_sensitive".
  - dateDisplayHint (string, optional): Indicates how date values should be displayed, with options such as 'absolute', 'absolute_with_relative', 'time_since', or 'time_until'.
  - description (string, required): A description of the property that will be shown as help text in HubSpot.
  - displayOrder (integer, optional): Properties are shown in order, starting with the lowest positive integer value.
  - externalOptions (boolean, optional): For default properties, true indicates that the options are stored externally to the property settings.
  - fieldType (string, required): Controls how the property appears in HubSpot.
  - formField (boolean, optional): Whether or not the property can be used in a HubSpot form.
  - groupName (string, required): The name of the property group the property belongs to.
  - hasUniqueValue (boolean, optional): Whether or not the property's value must be unique. Once set, this can't be changed.
  - hidden (boolean, optional): Whether or not the property will be hidden from the HubSpot UI. It's recommended this be set to false for custom properties.
  - hubspotDefined (boolean, optional): This will be true for default object properties built into HubSpot.
  - label (string, required): A human-readable property label that will be shown in HubSpot.
  - modificationMetadata (PropertyModificationMetadata, optional): 
  - name (string, required): The internal property name, which must be used when referencing the property via the API.
  - options (array, required): A list of valid options for the property. This field is required for enumerated properties, but will be empty for other property types.
  - referencedObjectType (string, optional): If this property is related to other object(s), they'll be listed here.
  - sensitiveDataCategories (array, optional): When sensitiveData is true, lists the type of sensitive data contained in the property (e.g., "HIPAA").
  - showCurrencySymbol (boolean, optional): Whether or not the property will display the currency symbol set in the account settings.
  - type (string, required): The property data type.
  - updatedAt (string, optional): The timestamp when the property was last updated, in ISO 8601 format.
  - updatedUserId (string, optional): The internal user ID of the user who updated the property in HubSpot. This field may not exist if the property was updated outside of HubSpot.
