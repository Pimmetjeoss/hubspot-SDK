### GET /crm/objects/2026-03/{objectType}
List
  - objectType (path, req): 
  - after (query, opt): The paging cursor token of the last successfully read resource will be returned as the `paging.next.after` JSON property of a paged response containing more results.
  - archived (query, opt): Whether to return only results that have been archived.
  - associations (query, opt): A comma separated list of object types to retrieve associated IDs for. If any of the specified associations do not exist, they will be ignored.
  - limit (query, opt): The maximum number of results to display per page.
  - properties (query, opt): A comma separated list of the properties to be returned in the response. If any of the specified properties are not present on the requested object(s), they will be ignored.
  - propertiesWithHistory (query, opt): A comma separated list of the properties to be returned along with their history of previous values. If any of the specified properties are not present on the requested object(s), they will be ignored. Usage of this parameter will reduce the maximum number of objects that can be read by a single request.
  Response 200: successful operation
  Response default:

## Schemas

### StandardError
  - category (string): The main category of the error.
  - context (object): Additional context-specific information related to the error.
  - errors (array): The detailed error objects.
  - id (string): A unique ID for the error instance.
  - links (object): URLs linking to documentation or resources associated with the error.
  - message (string): A human-readable string describing the error and possible remediation steps.
  - status (string): The HTTP status code associated with the error.
  - subCategory (object): A more specific error category within each main category.
