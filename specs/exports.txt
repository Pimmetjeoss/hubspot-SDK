## Schemas

### ErrorDetail
  - code (string): The status code associated with the error detail
  - context (object): Context about the error condition
  - in (string): The name of the field or parameter in which the error was found.
  - message (string): A human readable message describing the error along with remediation steps where appropriate
  - subCategory (string): A specific category that contains more specific detail about the error

### PublicExportResponse
  - createdAt (string): The timestamp when the export was created, in ISO 8601 format.
  - exportName (string): The name assigned to the export.
  - exportState (string): The current state of the export process.
  - exportType (string): The type of export, which can be either VIEW or LIST.
  - id (string): The unique ID of the export.
  - objectProperties (array): The list of properties exported for the associated object.
  - objectType (string): The associated CRM object being exported.
  - recordCount (integer): The total number of records included in the export.
  - updatedAt (string): The timestamp when the export was last updated, in ISO 8601 format.

### ActionResponseWithSingleResultURI
  - completedAt (string): The timestamp when the export was completed, in ISO 8601 format.
  - errors (array): 
  - links (object): A collection of related links associated with the export.
  - numErrors (integer): The number of errors encountered during the export process.
  - requestedAt (string): The timestamp when the export request was made, in ISO 8601 format.
  - result (string): The URL of the resulting file if the export status is COMPLETE.
  - startedAt (string): The timestamp when the export process started, in ISO 8601 format.
  - status (string): The current status of the export, which can be PENDING, PROCESSING, COMPLETE or CANCELED.

### StandardError
  - category (string): The main category of the error.
  - context (object): Context about the error condition
  - errors (array): The detailed error objects.
  - id (string): A unique ID for the error instance.
  - links (object): URLs linking to documentation or resources associated with the error.
  - message (string): A human readable message describing the error along with remediation steps where appropriate
  - status (string): The HTTP status code associated with the error.
  - subCategory (object): A specific category that contains more specific detail about the error

  - value (string): The value to match against the property.
  - values (array): The values to match against the property.
