## Schemas

### TestRequestContext
  - source (string, required): Indicates the source of the test request, with the only accepted value being 'TEST'.

### PublicActionFunction
  - functionSource (string, required): The source code or script that defines the function's behavior.
  - functionType (string, required): The type of function, with accepted values: POST_ACTION_EXECUTION, POST_FETCH_OPTIONS, PRE_ACTION_EXECUTION, PRE_FETCH_OPTIONS.
  - id (string, optional): The unique identifier for the action function.

### PublicFieldTypeDefinition
  - description (string, optional): A detailed explanation of the field's purpose.
  - fieldType (string, optional): The type of field, with accepted values including booleancheckbox, calculation_equation, checkbox, date, file, html, number, phonenumber, radio, select, text, and textarea.
  - helpText (string, optional): Additional information or guidance about the field.
  - label (string, optional): A user-friendly name for the field.
  - name (string, required): The internal name used to identify the field.
  - options (array, required): 
  - optionsUrl (string, optional): A URL that provides options for the field.
  - referencedObjectType (string, optional): The type of object that the field references, with accepted values including OWNER.
  - type (string, required): The data type of the field, with accepted values including bool, date, datetime, enumeration, json, number, object_coordinates, phone_number, and string.

### PublicActionDefinition
  - actionUrl (string, required): 
  - archivedAt (integer, optional): 
  - executionRules (array, optional):

  - labels (object, required): 
  - objectRequestOptions (PublicObjectRequestOptions, optional): 
  - objectTypes (array, required):

### PublicOption
  - description (string, optional): A description of the option.
  - displayOrder (integer, optional): The position of the option relative to others in the list.
  - label (string, required): A user-friendly label that identifies the option.
  - value (string, required): The actual value of the option.

### PublicActionDefinitionRequiresObjectResponse
  - requiresObject (boolean, required): Indicates whether a custom action definition requires an object.

### PublicConditionalSingleFieldDependency
  - controllingFieldName (string, required): The name of the field that determines the dependency.
  - controllingFieldValue (string, required): The value of the controlling field that triggers the dependency.
  - dependencyType (string, required): The type of dependency, with the default value being CONDITIONAL_SINGLE_FIELD.
  - dependentFieldNames (array, required):
