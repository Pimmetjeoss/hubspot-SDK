## Schemas

### StandardError
  - category (string): The main category of the error.
  - context (object): Additional context-specific information related to the error.
  - errors (array): The detailed error objects.
  - id (string): A unique ID for the error instance.
  - links (object): URLs linking to documentation or resources associated with the error.
  - message (string): A human-readable string describing the error and possible remediation steps.
  - status (string): The HTTP status code associated with the error.
  - subCategory (object): A more specific error category within each main category.
