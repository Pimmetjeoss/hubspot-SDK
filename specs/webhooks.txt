### SubscriptionBatchUpdateRequest
  - active (boolean, required): Whether to activate or pause the webhook subscription. If true, the subscription will send webhook notifications. If false, the subscription is paused and will not send notifications.
  - id (integer, required): The ID of the webhook subscription to update.

### SubscriptionResponse
  - active (boolean, required): Whether the subscription is active or paused. If true, the subscription will send webhook notifications. If false, the subscription is paused and will not send notifications.
  - createdAt (string, required): The timestamp when the webhook subscription was created, in ISO 8601 format (e.g., 2020-02-29T12:30:00Z).
  - eventType (string, required): The type of event to listen for. Accepted values include contact.creation, contact.deletion, contact.propertyChange, and similar event types for other CRM objects and custom objects.
  - eventTypeName (string, optional): The name of the event to listen for. This is used with custom objects to specify custom event types beyond the standard eventType enum values.
  - id (string, required): The unique ID of the webhook subscription.
  - objectTypeId (string, optional): The ID of the object type for the subscription. This can be a standard CRM object (e.g., 'contact', 'company', 'deal') or a custom object ID for custom object subscriptions.
  - propertyName (string, optional): The internal name of the property to monitor for changes. Only applies when eventType is propertyChange.
  - updatedAt (string, optional): The timestamp when the webhook subscription was last updated, in ISO 8601 format (e.g., 2020-02-29T12:30:00Z).

### SubscriptionCreateRequest
  - active (boolean, required): Determines if the subscription is active or paused. Defaults to false.
  - eventType (string, required): Type of event to listen for. Can be one of `create`, `delete`, `deletedForPrivacy`, or `propertyChange`.
  - eventTypeName (string, optional): The name of the event to listen for. This is used with custom objects to specify custom event types beyond the standard eventType enum values.
  - objectTypeId (string, optional): The ID of the object type for the subscription. This can be a standard CRM object (e.g., 'contact', 'company', 'deal') or a custom object ID for custom object subscriptions.
  - propertyName (string, optional): The internal name of the property to monitor for changes. Only applies when `eventType` is `propertyChange`.
